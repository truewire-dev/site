# Fonts

`newsreader-display.woff2` and `newsreader-display-italic.woff2` are Newsreader by
Production Type, distributed under the SIL Open Font License 1.1
(https://github.com/googlefonts/newsreader, https://openfontlicense.org). They are
the Latin subset of the variable font, instanced at optical size 60 with the weight
axis kept between 400 and 600, so each file is about 25 KB. They are used for
headings only; body text and the wire use the reader's system fonts, and nothing is
fetched from a third party.
